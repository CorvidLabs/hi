# hi (Human Intent)

Specs drift into coding intent: modules, contracts, API shapes. That is the right thing for a spec to do, and it is what spec-sync already checks. But by the time something is a spec, the thing a person actually wanted has usually been quietly translated away.

hi is where the untranslated version lives. Plain sentences about what someone wants to be able to do, each with an address that never moves, so tickets and specs can be generated from it instead of written alongside it.

It holds intent and identity. Nothing else. It stores no state, tracks no lifecycle, binds no evidence, and never fails a build because a criterion is unproven. The moment it does any of those, it becomes one more thing to maintain, and it stops being written.
